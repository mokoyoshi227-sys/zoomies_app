# Zoomies сервер (Supabase)

Апп GitHub Pages дээрээ үлдэнэ. Supabase нь бүртгэл, амьтад, зураг, найзууд, эрүүл мэндийн хөтлөл, тэмдэглэлийг хадгална.

## 1. Төсөл үүсгэх

1. https://supabase.com → **Start your project** → GitHub-аар нэвтэрнэ.
2. **New project**:
   - **Name:** `zoomies`
   - **Database password:** хүчтэй нууц үг үүсгээд өөртөө хадгална. Апп-д болон Claude-д **хэрэггүй**.
   - **Region:** Монголд ойр **Northeast Asia (Seoul)** эсвэл **(Tokyo)**.
   - **Plan:** Free.
3. Төсөл 1–2 минутад бэлэн болно.

## 2. Өгөгдлийн санг үүсгэх

1. Зүүн цэс → **SQL Editor** → **New query**.
2. Энэ хавтасны `schema.sql` файлын агуулгыг бүхэлд нь хуулж буулгана.
3. **Run** дарна. "Success. No rows returned" гэж гарвал болсон.

## 3. Апп-д хэрэгтэй хоёр утга

**Project Settings → API Keys** (эсвэл **Connect**) хэсгээс:

| Утга | Жишээ | Апп-д оруулах уу? |
|---|---|---|
| Project URL | `https://abcd1234.supabase.co` | ✅ Тийм |
| Publishable key (anon) | `sb_publishable_...` эсвэл `eyJ...` | ✅ Тийм. Нийтэд ил байхад аюулгүй, хандалтыг `schema.sql`-ийн дүрмүүд хамгаална |
| Secret key (service_role) | `sb_secret_...` | ❌ **Хэзээ ч үгүй.** Хэнд ч бүү өг, апп-д бүү оруул |

## 4. Нэвтрэх тохиргоо

**Authentication → Sign In / Providers → Email**:
- Email provider асаалттай байх.
- Туршилтын үед **Confirm email**-ийг унтрааж болно. Жинхэнэ хэрэглэгчидтэй ажиллахаас өмнө буцааж асаана.

**Authentication → URL Configuration**:
- **Site URL:** `https://mokoyoshi227-sys.github.io/zoomies_app/`
- **Redirect URLs:** дээрхийг болон туршилтын `http://localhost:5500/`-г нэмнэ.

## Хэн юуг харах вэ

- Өөрийн профайл, амьтад, хөтлөл, тэмдэглэлийг зөвхөн өөрөө харж, засна.
- Бусдын амьтныг зөвхөн "карт"-аар харна: нэр, төрөл, хүйс, төрсөн өдөр, үүлдэр, жин, зураг, эзний нэр. Утас, имэйл хэзээ ч харагдахгүй.
- Найзын хүсэлтийг зөвхөн серверийн функцээр илгээж, хариулна. Хоёр тал зэрэг хүсэлт илгээвэл тэр даруй найз болно.
- Найзаас хасвал хоёр талаас зэрэг хасагдана.
- Амьтны зургийн хаяг санамсаргүй тул таах боломжгүй. Хэрэглэгчийн профайл зураг хаалттай.

## Үнэгүй төлөвлөгөөний хязгаар

- 500 MB өгөгдлийн сан, 1 GB зураг, сард 50,000 хэрэглэгч.
- **7 хоног идэвхгүй байвал төсөл түр зогсоно.** Dashboard-оос дахин асаана.
- Автомат нөөцлөлт (backup) байхгүй. Жинхэнэ хэрэглэгчидтэй болоход Pro ($25/сар) руу шилжинэ.
