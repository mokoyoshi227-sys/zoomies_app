# Zoomies сервер (Supabase)

Апп GitHub Pages дээрээ үлдэнэ. Supabase нь бүртгэл, амьтад, зураг, найзууд, эрүүл мэндийн хөтлөл, тэмдэглэлийг хадгална.

## 1. Төсөл үүсгэх

1. https://supabase.com → **Start your project** → GitHub-аар нэвтэрнэ.
2. **New project**:
   - **Name:** `zoomies`
   - **Database password:** хүчтэй нууц үг үүсгээд өөртөө хадгална. Апп-д болон Claude-д **хэрэггүй**.
   - **Region:** Монголд ойр **Northeast Asia (Seoul)** эсвэл **(Tokyo)**.
   - **Plan:** Free.
3. Төсөл 1–2 минутад бэлэн болно.

## 2. Өгөгдлийн санг үүсгэх

1. Зүүн цэс → **SQL Editor** → **New query**.
2. Энэ хавтасны `schema.sql` файлын агуулгыг бүхэлд нь хуулж буулгана.
3. **Run** дарна. "Success. No rows returned" гэж гарвал болсон.

## 3. Апп-д хэрэгтэй хоёр утга

| Утга | Жишээ | Апп-д оруулах уу? |
|---|---|---|
| Project URL | `https://abcd1234.supabase.co` | ✅ Тийм |

| Secret key (service_role) | `sb_secret_...` | ❌ **Хэзээ ч үгүй.** Хэнд ч бүү өг, апп-д бүү оруул |

## Хэн юуг харах вэ

- Өөрийн профайл, амьтад, хөтлөл, тэмдэглэлийг зөвхөн өөрөө харж, засна.
- Бусдын амьтныг зөвхөн "карт"-аар харна: нэр, төрөл, хүйс, төрсөн өдөр, үүлдэр, жин, зураг, эзний нэр. Утас, имэйл хэзээ ч харагдахгүй.
- Найзын хүсэлтийг зөвхөн серверийн функцээр илгээж, хариулна. Хоёр тал зэрэг хүсэлт илгээвэл тэр даруй найз болно.
- Найзаас хасвал хоёр талаас зэрэг хасагдана.
- Амьтны зургийн хаяг санамсаргүй тул таах боломжгүй. Хэрэглэгчийн профайл зураг хаалттай.

## Үнэгүй төлөвлөгөөний хязгаар

- 500 MB өгөгдлийн сан, 1 GB зураг, сард 50,000 хэрэглэгч.
- **7 хоног идэвхгүй байвал төсөл түр зогсоно.** Dashboard-оос дахин асаана.
- Автомат нөөцлөлт (backup) байхгүй. Жинхэнэ хэрэглэгчидтэй болоход Pro ($25/сар) руу шилжинэ.

## Нэмэлт үйлчилгээнүүд: хоолны сануулга, эмчийн цаг, QR хүзүүвч, үрчлэлт, push мэдэгдэл

### 1. Өгөгдлийн сан
SQL Editor → **New query** → дараах файлуудыг **энэ дарааллаар** нэг нэгээр нь хуулж буулгаад **Run** дарна (өмнө ажиллуулсныг дахин ажиллуулсан ч болно):

1. `stars.sql`
2. `pet_types.sql`
3. `features.sql`

`features.sql` ажилласны дараа апп дээр хоолны нөөц, эмчийн цаг захиалга, QR хүзүүвч, үрчлэлт гарч ирнэ. Админ хэсэгт "Цаг захиалга", "Асрамж", "Үрчлэлт", "Үрчлэх хүсэлт", "Олдсон" табууд нэмэгдэнэ.

### 2. Асрамжийн газрын ажилтан
1. Админ хэсэг → **🏠 Асрамж** → "+ Асрамжийн газар нэмэх" → хадгална.
2. Тэр газрыг дахин нээгээд **Ажилтнууд** хэсэгт ажилтны имэйлийг бичээд "Нэмэх". Ажилтан эхлээд Zoomies апп-д тэр имэйлээр бүртгүүлсэн байх ёстой.
3. Ажилтан `…/zoomies_app/admin/` хаягаар өөрийн имэйл, нууц үгээр нэвтэрнэ. Зөвхөн өөрийн газрын амьтад, хүсэлтүүдийг харна.

### 3. Push мэдэгдэл (апп хаалттай үед утсанд ирэх мэдэгдэл)
Нууц түлхүүрүүд таны компьютерт `C:\Users\User\Documents\zoomies-push-secrets.txt` файлд байгаа. **Энэ файлыг GitHub руу хэзээ ч бүү оруул.**

1. **Edge Functions** → **Deploy a new function** → **Via Editor** → нэр: `push`.
   - Энэ хавтасны `functions/push/index.ts` файлын агуулгыг бүхэлд нь буулгана → **Deploy**.
   - Функцын **Settings** (эсвэл Details) → **Verify JWT** / "Enforce JWT verification"-ийг **унтраана** → Save.
2. **Edge Functions → Secrets** → `zoomies-push-secrets.txt` дотрох 4 утгыг нэмнэ: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (өөрийн имэйлээр), `HOOK_SECRET`.
3. **SQL Editor** → дараах 2 мөрийг ажиллуулна. `ТАНЫ_HOOK_SECRET`-ийн оронд файл дахь `HOOK_SECRET` утгыг хуулна (энэ SQL-ийг файлд хадгалж, GitHub руу бүү оруул):

```sql
insert into private.settings (key, value) values ('push_url', 'https://wwmwubwphslhjlstdgcn.supabase.co/functions/v1/push') on conflict (key) do update set value = excluded.value;
insert into private.settings (key, value) values ('hook_secret', 'ТАНЫ_HOOK_SECRET') on conflict (key) do update set value = excluded.value;
```

4. **Өдөр бүрийн сануулга** (өглөө 10:00-д: хоол дуусах, вакцин, маргаашийн цаг) `features.sql` ажиллахад автоматаар тохирно. Хэрэв SQL дуусахдаа "pg_cron not available" гэж бичвэл **Database → Extensions** → `pg_cron`-ийг асаагаад `features.sql`-ийг дахин ажиллуулна.
5. Апп дээр: **Профайл → Push мэдэгдэл**-ийг асаана. iPhone дээр апп-ыг эхлээд Share → **Add to Home Screen**-ээр суулгасан байх шаардлагатай (iOS 16.4+).

### Хэн юуг харах вэ (нэмэлт)
- **Эмчийн цаг:** хэрэглэгч зөвхөн өөрийн захиалгыг харж, цуцална. Баталгаажуулах, цуцлах эрх зөвхөн админд.
- **QR хүзүүвч:** уншуулсан хүн амьтны нэр, зураг, төрөл, үүлдэр, эзний нэрийг л харна. Утасны дугаар зөвхөн эзэн нь "Утасны дугаараа харуулах"-ыг асаасан үед харагдана. Олсон хүний мессежийг зөвхөн эзэн (болон спам устгах админ) харна. Нэг амьтанд цагт 5-аас олон мессеж илгээх боломжгүй.
- **Үрчлэлт:** амьтдын мэдээлэл бүгдэд нээлттэй. Хүсэлтийг илгээгч өөрөө, тухайн асрамжийн газрын ажилтан, админ л харна.
- **Хоолны нөөц:** зөвхөн эзэн өөрөө харна.

## Онцлох байршил (төлбөртэй, хугацаатай)
SQL Editor → **New query** → `featured.sql`-ийг бүхэлд нь хуулж буулгаад **Run** (`admin.sql`, `features.sql`-ийн дараа). Дахин ажиллуулсан ч болно.

Үүний дараа админ хэсэгт бараа, эмнэлэг, эмч, асрамжийн газрын засварын цонхонд **"Онцлох байршил"** гарна:
- Дуусах өдрийг сонгоно (эсвэл **+1 долоо хоног / +1 сар / +3 сар / +6 сар**). Тэр өдрийн эцэс хүртэл апп дээр дээгүүр, **"Онцлох"** шошготой гарна, дараа нь өөрөө буцаж энгийн болно.
- Нэг жагсаалтад (бараа / эмнэлэг / эмч / асрамж) **нэг дор 3** хүртэл. Хэд хэд байвал апп нээх бүрд дараалал нь солигдоно.
- Дуусахад **5 хоног** үлдвэл админ хэсгийн дээд талд сануулга гарна, байгууллагатай холбогдож сунгана.
- Зөвхөн админ тохируулна. Асрамжийн газрын ажилтан өөрийн газраа онцлох болгож чадахгүй.
