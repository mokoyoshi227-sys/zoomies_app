# Барааны зургууд

Барааны зургаа энэ хавтаст оруулна (**Add file → Upload files**).

- Формат: `.jpg`, `.png`, `.webp`
- Хэмжээ: 600–1000 пиксел өргөн хангалттай, нэг зураг 300 KB-аас бага байвал апп хурдан ачаална
- Нэр: латин үсэг, тоо, зураас ашиглана. Жишээ: `cat-bowl-orange.jpg` (зай, кирилл үсэг бүү ашигла)
- Тунгалаг дэвсгэртэй `.png` / `.webp` зураг картан дээр хамгийн гоё харагдана

Оруулсны дараа `products.json` дотор тухайн барааны `"photo"` талбарт бичнэ:

```json
"photo": "photos/cat-bowl-orange.jpg"
```

# Нүүр хуудасны зураг (`welcome-dog.jpg`)

Апп нээгдэхэд гардаг нэвтрэх хуудасны дэлгэц дүүрэн зураг. Солихдоо энэ хавтаст **Add file → Upload files** → шинэ зургаа яг **`welcome-dog.jpg`** гэж нэрлээд оруулна → **Commit changes**. Хуучин нь дарагдаж, 10–15 минутын дотор бүх утсанд (суулгасан апп дээр ч) шинэ зураг гарна. Өөр юм засах шаардлагагүй.

- Хэмжээ: **1290 × 2796 px** (босоо, 9:19.5), iPad дээр ч тод харагдана. Хамгийн багадаа 900 × 1950. `.jpg`, 400 KB-аас бага.
- iPad-ыг хэвтээ барихад зураг дэлгэцийн баруун хагаст гарч, лого, товчнууд зүүн талд байрлана. Тиймээс амьтны нүүр зургийн өргөний голд байвал аль ч байрлалд сайн харагдана.
- Зураг доод талаараа бэхлэгддэг. Дээрээс доош:
  - **Дээд 45%**: зөвхөн фон. Цагаан лого, бичиг энд гарна, тиймээс хэт цайвар биш өнгө байх ёстой. Богино дэлгэцтэй утсан (iPhone SE) дээр дээд талын ~18% тайрагдана.
  - **45–80%**: амьтны нүүр, толгой.
  - **Доод 20%**: товчнууд гарч, бага зэрэг бараандана. Нүүр биш, бие, хүзүүвч байж болно.
  - **Зүүн, баруун 5%**: чухал зүйл бүү байрлуул, нарийн утсан дээр тайрагдана.
- Фоны өнгө улбар шар биш бол `index.html` дотор `#E3A21A` (2 газар) өнгийг шинэ фоны өнгөөр солино. Зураг ачаалагдах хүртэл энэ өнгө хэдхэн хором харагддаг.
