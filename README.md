## Бараа нэмэх, засах

Бүх бараа **`products.json`** файлд байна. Үүнийг GitHub дээр шууд засна — програм суулгах шаардлагагүй.

1. Repo дотроо `products.json` файл дээр дарна.
2. Баруун дээд талын **✏️ (Edit this file)** товчийг дарна.
3. Засвараа хийнэ (доорх загварыг хар).
4. **Commit changes…** → **Commit changes** дарна.
5. 1–2 минутын дараа апп шинэчлэгдэнэ. Утсан дээрх апп-ыг хааж дахин нээхэд шинэ бараа гарна.

### Нэг барааны загвар

```json
{
  "id": "p13",
  "name": "Нохойн зөөлөн ор · M",
  "description": "Угааж болдог бүрээстэй, 60×45 см. Дунд нохойд тохиромжтой.",
  "price": 89900,
  "pets": ["dog"],
  "new": true,
  "photo": "photos/dog-bed.jpg",
  "art": ["bag", "#0F4C17", "#F26B12"]
}
```

| Талбар | Утга |
|---|---|
| `id` | Давхардахгүй дугаар: `p13`, `p14`… Сагсанд байгаа барааг энэ дугаараар таньдаг тул хуучин барааны `id`-г бүү соль. |
| `name` | Барааны нэр |
| `description` | Барааны тайлбар (дэлгэрэнгүй цонхонд гарна) |
| `price` | Үнэ, төгрөгөөр, зөвхөн тоо: `89900` (₮ болон таслал бичихгүй) |
| `pets` | Аль амьтанд: `"dog"` нохой, `"cat"` муур, `"bird"` шувуу, `"fish"` загас, `"rabbit"` туулай, `"hamster"` шишүүхэй. Хэд хэдийг бичиж болно: `["cat", "dog"]` |
| `new` | `true` бол картан дээр "Шинэ" тэмдэг гарна. Үгүй бол `false` |
| `photo` | Барааны зураг: `"photos/файлын-нэр.jpg"`. Хоосон `""` бол доорх `art` зурсан дүрс гарна |
| `art` | Зураггүй үед гарах дүрс (заавал биш). Төрлүүд: `bowl` аяга, `bag` уут, `mouse` хулгана, `rope` олс, `leash` оосор, `can` лааз, `wheel` дугуй, `carrot` лууван |

### Бараа нэмэх
Сүүлийн барааны `}` -ийн ард **таслал** `,` тавиад шинэ `{ … }` блок нэмнэ. Хамгийн сүүлийн блокийн ард таслал **бичихгүй**.

### Бараа устгах
Тухайн `{ … }` блокийг бүхэлд нь, ард нь байгаа таслалтай нь хамт устгана.

### Зураг солих / нэмэх
1. `photos` хавтсыг нээгээд **Add file → Upload files** → зургаа чирж оруулна → **Commit changes**.
2. `products.json` дотор тухайн барааны `"photo"`-д `"photos/зургийн-нэр.jpg"` гэж бичнэ.

Зургийн нэрэнд латин үсэг, тоо, зураас (`-`) л ашиглана.

### Анхаар
- Бүх бичвэр **давхар хашилт** `"…"` дотор байна. Тоо (`price`) болон `true`/`false` хашилтгүй.
- Алдаа гарвал (жишээ нь таслал дутуу) апп өмнөх, кодонд суулгасан бараагаа харуулна — эвдрэхгүй. Засварын дараа апп дээр бараа өөрчлөгдөөгүй бол таслал, хашилтаа шалгаарай. https://jsonlint.com дээр файлынхаа агуулгыг буулгаж шалгаж болно.
